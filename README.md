# 🌐 The Journey of a Data Packet
### Computer Networks — Unit 4: Network Layer

## 📌 Project Overview

This project explains the **Network Layer** of computer networks and how data packets travel from a sender to a receiver across interconnected networks. It covers IP addressing, packet delivery methods, routing techniques, and network troubleshooting tools through an educational video presentation.

## 🎯 Objectives

- Understand the role and functions of the Network Layer.
- Compare virtual-circuit and datagram networks.
- Learn the differences between IPv4 and IPv6.
- Understand IP packet structure, including the header and payload.
- Explore unicast, multicast, and anycast addressing.
- Learn how Ping and Traceroute help troubleshoot network connectivity.
- Understand routing tables and real-world networking applications.

## 📚 Topics Covered

1. **Introduction to the Network Layer** — How packets move across networks.
2. **Packet Delivery Models** — Virtual Circuit vs. Datagram.
3. **IP Addressing** — IPv4 and IPv6.
4. **IP Packet Structure** — Header and payload.
5. **Addressing Methods** — Unicast, Multicast, and Anycast.
6. **Network Troubleshooting** — Ping and Traceroute.
7. **Routing** — Routing tables, next hops, and routing algorithms.
8. **Real-World Applications** — Web browsing, video streaming, email, and cloud services.

## 🌍 Real-World Applications

The Network Layer plays an important role in:

- Delivering data between devices on different networks.
- Selecting routes through routers.
- Supporting websites and online applications.
- Enabling video streaming, email, and cloud communication.
- Diagnosing connectivity and routing problems.

## ✅ Key Takeaways

- IP addresses help identify packet destinations.
- Routers forward packets using routing information.
- IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses.
- IP packets contain a header and payload.
- Ping checks reachability and response times; Traceroute helps reveal the path packets take.
- Routing helps data reach its destination across interconnected networks.
